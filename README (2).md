
# Explainable AI-Based Financial Fraud Detection System

## Week 3: Machine Learning Model Training

### Objective
Build machine learning models to identify potentially fraudulent credit card transactions.

### Dataset
Credit Card Fraud Detection dataset.
Target column: Class
- 0 = Normal transaction
- 1 = Fraudulent transaction

### Models Trained
1. Logistic Regression
2. Random Forest Classifier

### Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

### Output Files
- logistic_regression_model.pkl
- random_forest_model.pkl
- feature_scaler.pkl
- model_comparison.csv
- week3_confusion_matrices.png
- week3_summary.json

### Important Note
Because fraudulent transactions are rare, precision, recall, and F1-score
should be considered along with accuracy.
